# Klartext

**Idee:** Die erste Überschrift ist keine Werbezeile, sondern die ehrliche Antwort des Kreditrechners.
Wer den Betrag verschiebt, liest oben «Das passt.», «Das wird knapp.» oder «Ehrlich gesagt: lieber weniger.» –
samt konkretem, kleinerem Betrag als Vorschlag (ein Klick übernimmt ihn). Der USP wird so nicht behauptet, sondern erlebt.

**Budget-Block:** Ein isometrischer Block aus den 30°-Flächen der Bildmarke zeigt das Monatseinkommen:
Fixkosten (Blau), Rate (Gold, bei Überlastung Rot) und Spielraum; eine rote Linie markiert die Tragbarkeitsgrenze.

**Technik:** HTML, CSS, Vanilla JS, SVG. Keine Abhängigkeiten. `prefers-reduced-motion` schaltet Animationen ab.

**Annahmen (Platzhalter):** 8.9 % eff. Jahreszins; «tragbar» = Rate ≤ 35 % des freien Budgets, «knapp» ≤ 60 %.
Kontaktdaten und Adresse sind Platzhalter.
